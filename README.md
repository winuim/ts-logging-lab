# ts-logging-lab

TypeScriptで既存の処理にログを付与する設計を段階的に学ぶ教材です。

## このブランチの状態

`publication-history` は、Zenn全11回に沿って公開用の履歴を再構築するための準備段階です。このコミットは教材第1回の完成版ではありません。各回のコード・テスト・実行手順は、記事との対応を確認しながら今後追加します。

初回コミットからNode.js 26系を前提とします。`.nvmrc` は `26`、`package.json` の `engines.node` は `>=26 <27` を指定しています。

現時点では依存関係・ソースコード・テスト・ビルド設定はありません。インストール、ビルド、テストの手順は教材の追加時に記載します。
